# Карелия

Учебный проект: одностраничный лендинг туристического маршрута по Карелии —
десять мест, связанных одной историей.

## Стек

- HTML5
- SCSS → CSS (компиляция через [Prepros](https://prepros.io/), автопрефиксы)
- Шрифт Inter локально (`fonts/`), векторный SVG-логотип (`img/`)

## Запуск

1. Открой `index.html` через Live Server (порт задан в `.vscode/settings.json`)
   или просто двойным кликом в браузере.
2. Вёрстку правим в `style.scss` — Prepros сам компилирует его в `style.css`.

## Структура

```
index.html      — разметка: шапка, hero-секция; блок «О нас» временно убран —
                станет отдельной страницей
style.scss      — исходник стилей (править здесь)
style.css       — скомпилированный CSS (не править руками)
js/app.js       — данные маршрута и логика карты, списка и мобильного меню
img/            — логотип, фото остановок (place-01…10.jpg), панорама-заглушка
fonts/          — Inter (Regular / Medium / Bold)
prepros.config  — конфигурация сборки
```

## Статус

В разработке: стартовый экран (шапка с якорной навигацией и hero), раздел с
картой маршрута (2ГИС): список десяти остановок, описание каждой точки и
финальная карточка после маршрута. Мобильная версия: кнопки «Начать» и
«Остановки» над картой, остановки — в выезжающем меню. Фото остановок
загружены; фон главной — пока пустой (есть рисованная заглушка в
img/hero-bg.svg), «О нас» будет отдельной страницей.
